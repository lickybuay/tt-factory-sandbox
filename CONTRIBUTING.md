# Contributing

Thanks for helping out. This is a small testing repository, so the process is short.

## Install

You need Node 20 or newer. There are no dependencies, so there is nothing to install beyond Node.

```sh
git clone https://github.com/lickybuay/tt-factory-sandbox.git
cd tt-factory-sandbox
```

## Run the tests

```sh
npm test
```

All tests must pass before you open a pull request. Add or update a test for any behaviour you change.

## Open a pull request

1. Create a branch from `main`: `git switch -c my-change`.
2. Make your change and commit it with a clear message.
3. Push the branch: `git push -u origin my-change`.
4. Open a pull request against `main` on GitHub and describe what changed and why.
