# Contributing

Thanks for helping out. This is a small test repository, so the process is light.

## Install

Requires Node 20 or newer. There are no dependencies to install.

```sh
git clone https://github.com/lickybuay/tt-factory-sandbox.git
cd tt-factory-sandbox
```

## Run the tests

```sh
npm test
```

All tests must pass before you open a pull request.

## Open a pull request

1. Create a branch from `main`: `git switch -c my-change`.
2. Make your change and add or update tests for it.
3. Run `npm test`.
4. Commit with a short, descriptive message and push your branch.
5. Open a pull request against `main` describing what changed and why.
