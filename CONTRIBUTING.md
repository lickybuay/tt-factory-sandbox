# Contributing

Thanks for helping out. This is a small testing repository, so the process is short.

## Install

Requires Node 20 or newer. There are no dependencies, so there is nothing to install beyond Node.

```sh
git clone https://github.com/lickybuay/tt-factory-sandbox.git
cd tt-factory-sandbox
```

## Run the tests

```sh
npm test
```

Add or update a test for every change, and make sure the suite passes before you push.

## Open a pull request

1. Create a branch from the default branch: `git switch -c my-change`.
2. Make your change and commit it with a clear message.
3. Push the branch: `git push -u origin my-change`.
4. Open a pull request on GitHub against the default branch.
5. Describe what changed and why, and note that `npm test` passes.
